# Coach Equipment Colour Check — Matchday Edition

Free, original educational football game **created, developed and published by Cornelius Aurelius**.
Official game: https://cornelius-aurelius.github.io/Coach-Equipment-Colour-Check/
Creator: https://corneliusaurelius.com/

## What it does

12 curated equipment scenarios (cones, bibs, balls, markers) train players and coaches to spot colour-dependent signals and to use extra cues: clear contrast, shapes, patterns, numbers and labels. Correct decisions lead to accessible explanations. Matchday gives three chances, point bonuses for streaks, and an on-device high score. Practice is non-scoring, no-loss learning.

## Controls

- Touch or click **Clear setup** or **Colour risk**.
- Keyboard **1** or **C**: clear setup; **2** or **R**: colour risk; **Enter**: next drill; **Esc**: pause/resume; **H**: grayscale contrast hint.
- Grayscale is a rough luminance aid and **is not** a simulation of colour vision deficiency.
- No automatic timer. No tracking or account. Browser local storage only for high score.

## Development

Static HTML/CSS and native ES modules. No build, ads, trackers, external dependencies or server. GitHub Pages deployment from `main` root. Run `node --test tests/*.test.mjs` to validate progression and stage integrity. For local browser test, `python3 -m http.server 8000`.
